# Usage Capsule

[简体中文](README.zh-CN.md) · [English](README.md) · **日本語** · [한국어](README.ko.md)

Codex の5時間枠と週間上限を確認できる、小さな macOS デスクトップウィジェット。光沢のあるダークガラス、温かみのある金属の縁、5段階のカラー表示。通常の表示サイズは **184 × 60 pt** です。

![Usage Capsule と概要パネル。表示値はサンプルです](docs/preview-ja.png)

## 0.10.1 プレビューの機能

- 実際の期間に基づいて5時間枠と週間枠を表示。残量、使用率、リセット時刻、カウントダウンを確認できます。
- 概要にアカウントが返すプラン名を表示。Pro 系で有限の5時間枠が返らない場合は **∞**、週間枠は実値を表示します。∞ は5時間の上限のみを意味し、返された有限の枠が優先されます。
- Free／Go はローカル Codex とアカウントが情報を提供する範囲で基本対応。不明な値はゼロや無制限として扱いません。
- プランと使用量を **60秒ごと**に確認。手動更新、対応するアカウント通知、アプリ再アクティブ化、Mac 復帰時にも再確認します。瞬時の監視ではなく、サーバー側の更新に遅れが生じることがあります。
- 直近7日間の Token 消費をセル表示。ホバーまたは選択でその日の報告値を確認できます。
- 光沢のあるダークガラスと金属の縁、**184 × 60 pt**、100–150% の拡大、最前面表示。残量に応じた5段階の色で、中程度でも明るさを保ちます。
- ホバーでアニメーション表示、クリックで固定、×／Escape で閉じる。システムの動きを減らす設定にも対応。
- 全ウィンドウからドラッグ、位置を保存。右クリック／メニューバーから更新、設定、非表示、終了。
- 簡体字中国語、英語、日本語、韓国語。システム追従と手動切り替え。
- **自動再開は明示的に選んだ会話のみ**。初期選択はありません。許可は単発または継続を選べ、許可後の明確な利用枠中断にだけ使います。過去の失敗や即時実行には使いません。
- 許可済み／会話選択／履歴の3タブ、読み込み済み会話・プロジェクトの検索、追加読み込み、利用可能な完全タイトル、優先度の並べ替え。
- 回復後は元の Codex キューへ一度引き渡し。該当する応答と最終返信の終了確認、またはユーザーの明示的な確認後に次を許可します。不明な状態では待機します。
- 全体の一時停止、許可解除、未実行キューの取り消し、5時間・週間の確保値。確保値は新規引き渡しを止めるもので、実行中の消費上限ではありません。
- ローカル結果カード、元の会話へのリンク、任意の終了／失敗通知。返信の抜粋に追加の要約モデルは使いません。応答終了はプロジェクト全体の完了とは限りません。
- インスタンス間で共有するモード別の許可・解除、アカウント紐付け、永続化した引き渡し記録。不確かな送信は再送せず、実行中の停止と承認は元の Codex で行います。
- リセットカードは0.8秒長押しで確認画面を開き、明示的な確認後にだけ送信。直前にアカウントとカードを再確認します。自動再開やデモではカードを使いません。
- ログイン期限切れ時は一度だけ接続を再作成。認証が失敗し続ける場合は古い残量・プランを消去し、一時的な障害は前回確認値と明示します。
- アカウント更新通知で古い実行判断を無効化。自動再開にはバックエンドの明示的な利用許可と確認済みの適用枠が必要です。

**プレビューの範囲：**アプリ実行中かつ Mac 起動中のみ監視します。API 対応は Codex／アカウントに依存します。Pro／Free／Go はシミュレーション、Plus の読み取りと実キュー／履歴経路は確認済みです。Free／Go の週間枠のみで見逃したリセットの推定は保守的に扱います。[動作の詳細](docs/AUTO_RESUME.md)・[検証範囲](docs/VALIDATION.md)。

## 再開モード

タスクごとに「一度だけ再開」（既定）または「継続再開（回数制限なし）」を選択できます。継続モードは許可後の使用上限による中断を、回復のたびに再開します。解除・全体一時停止が可能です。通常の応答終了、ユーザー入力待ち、手動停止、その他のエラーでは新しいラウンドを開始しません。中断ごとの永続記録で重複を防ぎ、古い選択や使用済みの許可を有効なチェックとして表示しません。

## 必要環境とインストール

**Apple Silicon Mac、macOS 13以降、Xcode Command Line Tools** が必要です。実際の利用状況の取得には、ローカルでログイン済みの Codex CLI が必要です。

Codex に次のように依頼できます：

> $skill-installer で https://github.com/guihaoyegui-ctrl/usage-capsule の skills/usage-capsule をインストールし、$usage-capsule で Mac 上にアプリをビルド、インストール、起動してください。

手動で行う場合は、ダウンロードしたリポジトリ内で実行します：

```sh
zsh skills/usage-capsule/scripts/capsule.sh doctor
zsh skills/usage-capsule/scripts/capsule.sh install
zsh skills/usage-capsule/scripts/capsule.sh start
```

アプリはローカルでビルドされ、`~/Applications/Usage Capsule.app` に配置されます。現在はアドホック署名のプレビュー版で、Developer ID による公証はありません。Gatekeeper を無効化せず、ソースを確認してビルドしてください。コンパイラがない場合は `xcode-select --install` を使用します。

右クリックまたはメニューバーから設定・更新・非表示・終了を選択できます。設定で日本語を選ぶか、`zsh skills/usage-capsule/scripts/capsule.sh language ja` を実行してください。

`preview` はサンプル PNG を生成します。`demo` はインストール済みアプリが停止中の場合にデモを開きます。これらはアカウント利用状況を取得しません。Skill のインストールだけではアプリは起動しません。クラウドのみの環境ではデスクトップに表示できません。

## データについて

60秒ごとにローカル Codex app-server のアカウント情報を読み取ります。照会自体はモデルの生成ターンを作成しません。実際の自動再開は利用枠を消費します。既存の Codex ログインを使用し、開発者のサーバーや分析サービスには送信しません。詳細は [Privacy](docs/PRIVACY.md) を参照してください。

このアプリはコミュニティプロジェクトであり、OpenAI の公式製品ではありません。日別消費量やリセットカードは CLI とアカウントの対応状況に依存します。不明な値はゼロとして表示しません。[検証範囲](docs/VALIDATION.md)と[トラブルシューティング](docs/TROUBLESHOOTING.md)もご確認ください。

このプレビューには、まだオープンソースライセンスが選択されていません。
